Experiment idea

I am toying with the idea of adding a "return to top" button. This can be done with jQuery or just simple JavaScript. The button should appear as soon as the user has scrolled a certain "distance" down the page. I do not want to have to alter the code for each of my pages, so I am also looking into ways to do it in one place and then just reference that location on all my respective subpages.

I found this info to help me with the jQuery:

Ever read a really long blog post or article and then had to scroll all the way up to the top of the screen to get to the menu? It can be a little frustrating. It’s easy to fix, you can have a fixed menu or as you’ll see here you can provide a quick and stylish way to get back to the top with jQuery.

Using HTML, we need to add a "back to top" link. We then need to style and position it. Using CSS, the position is set to fixed and it is moved to the bottom right of the screen. Some other styling can also be set, such as colour and opacity.

Next, we need to add jQuery to the page.

The jQuery is pretty simple:
1. set offset (after how much scrolling should the button appear)
2. how long do we want the effect to last?
3. make the button visible when the user scrolls

Using an external JavaScript file to add the button to all pages:

You can use an external JavaScript file with the script tag to essentially repeat the same "instructions" on every relevant page.

On my Home page, I first used inline JavaScript to add the "toTop" button, but then I externalised the same code into a .js file to be referenced on all subpages. This makes the code reusable and follows the "write less, do more" idea.
